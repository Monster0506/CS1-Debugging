# Lab_50 - Priority Queue and Multimap

Two small programs. Build each one: `g++ -std=c++17 -Wall lemons.cpp -o lemons` and `g++ -std=c++17 -Wall oranges.cpp -o oranges`.

The output is random, so check it by reasoning: change `srand(time(nullptr))` to `srand(1)` while debugging to get the same output every run.
