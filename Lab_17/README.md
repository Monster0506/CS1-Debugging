# Lab_17 - Pointers and Dynamic Memory

Build with: `g++ list.cpp main.cpp -o list`

Run the dialog at the top of `main.cpp`, then also try: removing the first element, the last element, and the only element; adding after removing.

If you can, run it under a memory checker (`valgrind`, or `g++ -fsanitize=address -g`) once it appears to work.
