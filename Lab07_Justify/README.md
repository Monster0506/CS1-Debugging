# Lab 7 - Strings and File I/O

`justify.cpp` justifies text to 90 columns. Make a small input file (a few long sentences with commas and periods, plus one short last line) and check the output file line by line. A quick way to count characters: open the output in an editor that shows the column number.

Ask yourself: what does `find()` return when it finds nothing? What happens if you use that value anyway?
