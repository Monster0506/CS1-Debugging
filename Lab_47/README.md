# Lab_47 - Roster with Sequential Containers

Build with `g++ -std=c++17 -Wall roster.cpp -o roster` and run `./roster cs1.txt cs2.txt cs3.txt dropouts.txt`. The expected output is in the comment at the top of `roster.cpp`.

The data structure is a vector of lists; each list holds the student's name first and then the courses. Draw it for the sample files. Pay attention to what happens to iterators when you erase from a container.
