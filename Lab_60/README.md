# Lab_60 - Observer: Coffee Shack

Build with `g++ -std=c++17 -Wall -g main.cpp drink.cpp -o coffeeshack` and run `./coffeeshack < input.txt`, then run under `valgrind`. The expected behavior is in the comment at the top of `main.cpp`.

Who is the subject, who are the observers, and what does `notifyObservers` hand to each of them? Be careful about references into a container that you erase from.
