# Lab_62 - Command and Memento: Document

Build with `g++ -std=c++17 -Wall -g document.cpp -o document` and run `./document < input.txt`, then run interactively and try every option (also `u` with nothing to undo, and `r` with a number that does not exist). Run under `valgrind` too.

Look at how the main loop starts: is every variable defined before it is read?
