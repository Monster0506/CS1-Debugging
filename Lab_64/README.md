# Lab_64 - Mediator and Flyweight: ATC

Build with `g++ -std=c++17 -Wall atc.cpp -o atc` (add `-pthread` if the linker asks for it) and run it in a terminal. The expected dialogue is in the comment at the top of the file.

Who knows about whom? Check that flights only talk to the controller. Check which data is shared and which is not.
