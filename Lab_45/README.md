# Lab_45 - Word Count

Build with `g++ -Wall -g wordListMain.cpp -o wordcount` and run `./wordcount sample.txt`, then run under `valgrind`. The expected output is in the comment at the top of `wordListMain.cpp`.

`WordList` owns a dynamic array, so it needs the big three (copy constructor, assignment, destructor). Decide for each one whether it is correct.
