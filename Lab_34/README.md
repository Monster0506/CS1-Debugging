# Lab_34 - Debugging with Print Statements

`bug1.cpp` prints several sets of random numbers with no duplicates inside a set. It does not do that yet.

Compile with `g++ -Wall bug1.cpp -o buggy`. Read the warnings too. Use `std::cerr` print statements (the binary-search-the-bug idea: top of main, bottom of main, then in between) to find each problem. Fix one bug at a time and re-run after every fix.
