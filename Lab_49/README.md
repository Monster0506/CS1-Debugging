# Lab_49 - Roster with set

Build with `g++ -std=c++17 -Wall rosterSet.cpp -o roster` and run `./roster cs1.txt cs2.txt cs3.txt dropouts.txt`. The expected output is in the comment at the top of `rosterSet.cpp`.

A `set` decides that two elements are the same when neither is less than the other. Think about what that means for your `operator<`. Also note that one of the dropouts is not enrolled in any course.
