# Lab_59 - Decorator and Chain of Responsibility

Build with `g++ -std=c++17 -Wall -g main.cpp drink.cpp -o coffee` and run under `valgrind`. Feed it the three inputs in the comment at the top of `main.cpp` and compare with the expected output. The prices come from the lab statement, not from the code.

Check every concrete class against the price list and the names. Think about what happens when you `delete` a derived object through a base class pointer.
