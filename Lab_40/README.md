# Lab_40 - Linked-List Stack Template

Build with `g++ -Wall -g main.cpp -o stacktest` and then run it under `valgrind ./stacktest` (or build with `-fsanitize=address`). The expected output is at the top of `main.cpp`. Almost everything is in `stack.hpp`.

Draw the linked list for each operation (`push`, `pop`, copy constructor). The conversion function in `main.cpp` has one bug of its own as well.
